# IntelliDocs AI - Application Screenshots

This directory is designated for high-resolution screenshots of the running IntelliDocs AI platform across all 15 operational routes.

## Captured Interface Views
- `01_login.png`: Split brand panel with violet gradient and authentication form.
- `02_dashboard.png`: Main learning dashboard with live study streaks, metrics, and recent documents.
- `03_document_upload.png`: Drag-and-drop document upload with real-time extraction progress.
- `04_document_library.png`: Document explorer with filtering, search, and page counts.
- `05_nlp_analysis.png`: Educational NLP inspector (Tokens, POS tags, Entities, N-grams, Readability metrics).
- `06_summarization.png`: Extractive vs Abstractive summarization with mode controls and ROUGE metrics.
- `07_keywords_topics.png`: Keyword extraction (RAKE, TextRank, Hybrid) and LDA / K-Means topic clusters.
- `08_rag_qa_chat.png`: Grounded Q&A with hybrid retrieval, source citations, and confidence scores.
- `09_question_generation.png`: Automated question generator across 7 types and 3 difficulty tiers.
- `10_quizzes.png`: Interactive timed quiz interface with question navigator grid.
- `11_quiz_results.png`: Evaluation analytics with topic breakdowns and weak area diagnostic alerts.
- `12_study_assistant.png`: Pedagogical AI tutor supporting 4 educational explanation modes.
- `13_flashcards.png`: Spaced repetition flashcards powered by the SuperMemo SM-2 algorithm.
- `14_analytics.png`: Learning analytics dashboard showing mastery progress and study streaks.
- `15_settings.png`: System preferences, model selection, and storage telemetry.
